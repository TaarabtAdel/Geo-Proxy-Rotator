Geo Proxy Rotator

Cấu hình proxy, bài viết và lịch sử chạy. Mọi profile chọn cùng một file hoặc thư mục để dùng chung dữ liệu.

Nơi lưu dữ liệu

Chọn một file JSON có sẵn, hoặc một thư mục. Thư mục sẽ dùng file geo-proxy-data.json. Mỗi profile Chrome chỉ cần chọn đúng chỗ đó một lần.

Chưa chọn nơi lưu.

Danh sách proxy

Nút lấy danh sách gộp mọi URL bên trên. Dòng LINK|socks4 ra socks4://ip:port, LINK|socks5 ra socks5://ip:port, dòng không hậu tố giữ nguyên ip:port (hoặc protocol có sẵn trong dữ liệu). Proxy viết tay: ip:port, ip:port:user:pass, socks4://ip:port hoặc socks5://ip:port. Cột Trạng thái cập nhật khi rotator đang chạy: Live, Không, Đang thử, Đang dùng hoặc Bận. Proxy đang Bận là profile khác đang mở, profile này sẽ bỏ qua cho đến khi profile kia dùng xong.

Nhịp chạy

Sau khi mở bài, extension chờ trang tải tối đa “Timeout tải bài viết” rồi vẫn chuyển sang đếm chờ min–max (100–120s) dù tab còn quay vòng. Proxy chậm nên tăng timeout tải bài hoặc giảm min–max để test nhanh hơn.
